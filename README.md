# JW SOFT G7 Themes

그누보드7용 유료 분야별 테마를 기획·제작·관리하는 비공개 저장소입니다.

**현재 단계: 일반 기업 홈페이지용 `JW BUSINESS 01` 제작. 범용 B2B 홈과 내부 페이지·게시판·문의 작성 화면, 구조 프리셋 3군, 테마 제작 하네스를 구현했습니다. 로컬 G7 설치·편집·방문자 비밀글 작성/열람/수정·모바일·검색엔진 HTML·고객 편집 보존을 확인했으며, 실제 레이아웃 데이터 팩 연결을 진행합니다.**

## 다음 작업 시작

[START-HERE](docs/START-HERE.md)에서 결정된 방향, 남은 선택, 첫 작업 순서를 확인합니다.

1. 레이아웃 데이터 프로젝트의 범용 B2B 기업 팩으로 실제 메뉴·페이지·게시판·게시물·이미지를 설치합니다.
2. 설치된 데이터로 모든 PC·모바일 메뉴와 목록·상세·문의 경로를 확인합니다.
3. 팩 재설치·제거 시 고객 수정을 보존하고 긴 한글·빈 상태·이미지 누락을 확인합니다.
4. 테마와 데이터 팩의 지원 조합·설치·업데이트 절차를 판매 문서에 고정합니다.

## 저장소 경계

- 이 저장소: 테마 디자인·레이아웃·컴포넌트·에셋·제작 도구·상품 문서.
- G7 코어: 인증·데이터·렌더 엔진·원본 저장과 공개 편집 계약.
- Page Builder: 별도 제품의 편집 확장. 지원 조합이 검증된 기능만 연동합니다.
- 테마별 버전과 출시는 독립적입니다. 저장소 전체를 구매자에게 배포하지 않습니다.
- 개발 기준은 TypeScript·React·CSS·JSON, 도구 제어는 Python을 권장합니다. 고객에게는 사전 빌드된 자산을 제공합니다.

판매 가격·이용 범위·지원 기간·배포 채널은 미정입니다. 이 문서 준비가 판매 가능한 제품이나 호환성 검증 완료를 뜻하지 않습니다.
