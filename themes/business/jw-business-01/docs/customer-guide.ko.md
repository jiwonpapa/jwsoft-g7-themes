# JW BUSINESS 01 설치·사용 안내

대상 버전은 `jwsoft-business01` 0.1.x입니다. G7 `>=7.0.10`, `sirsoft-page >=1.1.1`, `sirsoft-board >=1.1.1`이 필요합니다. 쇼핑몰·예약 기능은 포함하지 않습니다.

## 설치

1. G7 관리자에서 테마 ZIP `jwsoft-business01-0.1.0.zip`을 업로드합니다.
2. manifest 검사가 통과하면 `JW BUSINESS 01`을 활성 테마로 선택합니다.
3. 홈·페이지·게시판 기본 화면이 표시되는지 확인합니다.
4. 사이트 구성 팩을 사용할 경우 테마 설치 뒤 레이아웃 데이터 설치 모듈에서 `business.b2b-default` 프로필을 설치합니다.

설치 ZIP에는 브라우저 실행에 필요한 CSS·JavaScript·레이아웃·언어·계약·라이선스가 모두 포함됩니다. 고객 서버에서 Node.js, npm, Python 실행이나 외부 CDN 연결이 필요하지 않습니다.

## 기본 사이트 구조

테마의 기계 판독형 기준은 `contracts/site-structure.json`입니다. 설치 모듈은 이 계약의 논리 키를 실제 G7 페이지·게시판 ID와 주소로 해석한 뒤 메뉴와 홈 슬롯을 연결합니다.

| 상위 메뉴 | 연결 대상 |
|---|---|
| 회사소개 | 회사소개, 비전과 가치, 연혁, 팀, 오시는 길 |
| 사업분야 | 서비스, 진행 과정 |
| 프로젝트 | 프로젝트 게시판과 상세 |
| 인사이트 | 인사이트, 공지사항, FAQ |
| 문의하기 | 비회원 비밀 문의 작성, 문의 안내, 개인정보 안내 |

사이트 구성 팩을 설치하지 않아도 위 상위 메뉴와 기본 홈은 표시됩니다. 상단과 홈의 `문의하기`는 `inquiries` 게시판 작성 화면으로 바로 연결됩니다. 팩 설치 뒤에는 생성된 실제 페이지·게시판·게시물이 같은 경로에 연결되어야 합니다. 랜덤 생성 콘텐츠는 지원하지 않으며, 검토된 고정 데이터 팩만 사용합니다.

데모 게시판은 PC·모바일 모두 페이지당 5건, 최소 6건으로 구성해 페이지 이동 화면까지 확인할 수 있어야 합니다. 설치 완료 판정은 홈뿐 아니라 모든 일반 페이지·게시판·문의 작성 화면을 포함하며, 팩 제거 시 고객이 수정한 슬롯과 콘텐츠를 보존해야 합니다.

## 화면 프리셋

G7 레이아웃 편집기에서 아래 프리셋을 선택할 수 있습니다.

- 헤더: 기본형, 오버레이형, 디렉터리형
- 히어로: 커버형, 분할형, 에디토리얼형
- 모바일 메뉴: 패널형, 드로어형, 전체 화면형

프리셋은 구조와 반응형 규칙을 함께 바꿉니다. 텍스트·링크·이미지는 기존 G7 편집 데이터를 유지합니다. 직접 수정한 레이아웃은 업데이트 때 보존 정책을 사용해야 합니다.

## 콘텐츠 작성

일반 페이지는 `contracts/page-content.json`에 선언된 시멘틱 클래스를 지원합니다. 회사소개·가치·연혁·팀·인증·파트너·서비스·소개형 제품·과정·FAQ·연락처·위치·개인정보 구조를 같은 페이지 라우트에서 표현합니다. 소개형 제품 블록은 사진·설명·사양 표시에 한정되며 장바구니·주문 기능을 만들지 않습니다. 게시판 목록은 `cases`에서 이미지 중심 프로젝트 그리드를 사용하고, `resources`·`notices`는 읽기 중심 목록을 사용합니다. 회사·서비스·프로젝트·인사이트·문의 계열은 테마에 포함된 전용 히어로 사진을 사용하며, 모바일에서는 사진과 제목이 위아래로 분리됩니다.

이미지는 G7 미디어 또는 사이트 구성 팩으로 등록합니다. 본문 안의 실행 스크립트, iframe, 인라인 스타일, 폼은 제거됩니다. 아이콘은 테마에 포함된 단색 Lucide SVG만 사용합니다.

## 업데이트

고객이 편집한 레이아웃을 유지하려면 `keep` 전략을 사용합니다.

```sh
php artisan template:update jwsoft-business01 \
  --zip=/path/to/jwsoft-business01-0.1.0.zip \
  --layout-strategy=keep \
  --force --no-interaction
```

`overwrite`는 테마 기본 레이아웃으로 되돌릴 때만 사용합니다. 테마 업데이트는 설치된 페이지·게시판·게시물·첨부 이미지를 재설치하거나 삭제하지 않습니다.

## 접근성과 동작

- 모바일 메뉴는 키보드 조작, ESC 닫기, 초점 복귀와 배경 스크롤 잠금을 지원합니다.
- `prefers-reduced-motion`이 설정되면 패럴랙스와 등장 전환을 생략합니다.
- JavaScript가 늦게 실행되거나 실행되지 않아도 본문과 이미지가 기본 HTML에 남습니다.
- 키보드 초점 표시와 입력 필드 레이블을 유지합니다.

## 확인할 문제

- 설치가 거부되면 G7과 필수 페이지·게시판 모듈 버전을 확인합니다.
- 메뉴 링크에서 대상 없음 화면이 나오면 사이트 구성 팩 설치 결과에서 해당 논리 키의 페이지·게시판 생성 여부를 확인합니다.
- 업데이트 뒤 편집 내용이 초기화되었다면 사용한 레이아웃 전략을 확인합니다.
- 테마 ZIP에는 상품·결제·주문·배송 화면이 없으며 해당 기능은 별도 상품 범위입니다.
