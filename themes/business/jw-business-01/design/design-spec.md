# JW BUSINESS 01 디자인 규격 v0.1

상태: 첫 1번 도안의 여백·타이포·정보 위계를 유지한 범용 B2B 기업 규격. 로컬 G7 브라우저에서 기본형과 분할·에디토리얼 조합, 모바일 3종을 확인했습니다.

이전 산업설비 도안은 [보류 자료](archive/industrial-prototype/proposals/2026-09-09/a-precision.png)로 이동했습니다. 제품에는 해당 도안의 정돈된 조형만 적용하고 산업설비 콘텐츠·이미지는 사용하지 않습니다.

## 시각 방향

흰 배경, 잉크 네이비 글자, 한 계열의 파란 강조색과 큰 사진으로 신뢰감 있는 일반 기업 브랜드를 표현합니다. 회사·서비스/제품·사례·자료·문의에 같은 정보 위계와 여백을 적용하고 업종 데이터 팩이 사진과 문구를 바꿔도 조형이 유지되어야 합니다.

- 시각 명제: 큰 사진과 절제된 선, 넓은 여백으로 신뢰와 전문성을 보여주는 현대적인 기업 브랜드.
- 공통 콘텐츠 순서: 핵심 약속 → 역량·사업 → 서비스/제품 → 사례 → 정보·자료 → 문의.
- 기본 데모 적용: 기업 과제 → 전략·디지털·운영 역량 → 대표 서비스 → 프로젝트 → 인사이트 → 문의.
- 상호작용 명제: 히어로·대표 사례 이미지에 낮은 강도의 스크롤 깊이를 주고, 핵심 섹션은 위·좌·우에서 짧게 등장하며, 서비스 이미지는 hover에서만 작게 확대합니다. 모든 효과는 `prefers-reduced-motion`을 존중하고 JavaScript 없이도 본문과 이미지가 그대로 보입니다.
- 아이콘 명제: Lucide의 단색 선형 SVG만 사용합니다. 버튼·서비스·업무 단계·자료 링크처럼 탐색을 빠르게 하는 위치에 한정하고, 컬러 아이콘·이모지·유니코드 화살표를 UI에 사용하지 않습니다.

## 구현 구조

- JSON UI: 페이지·섹션·슬롯·데이터 소스·시멘틱 클래스 조립.
- TypeScript/React: 반복 상호작용, 접근성 동작, 공개 컴포넌트.
- CSS: 테마 토큰과 `jw-` 시멘틱 클래스.
- Tailwind CSS: `@apply`에서 반복 스타일을 조합하는 유틸리티 원본.
- Motion: DOM/WAAPI 경량 경로로 스크롤 등장과 이미지 깊이 효과를 제공합니다.
- Lucide: 필요한 아이콘만 번들에 포함하는 단색 SVG 레지스트리입니다.

첫 기반 클래스는 `jw-container`, `jw-section`, `jw-section__header`, `jw-eyebrow`, `jw-display-title`, `jw-body-copy`, `jw-button`, `jw-button--primary`, `jw-button--secondary`, `jw-text-link`, `jw-media`입니다. 구조 선택은 `editor-spec.json`의 고정 `jw-` 클래스 토큰만 사용합니다.

## MVP 화면

1. 공통 헤더·메뉴·모바일 메뉴·푸터와 기획서에 정의한 구조 프리셋.
2. 홈.
3. 회사소개·비전·연혁·조직·오시는 길.
4. 사업·서비스와 소개용 제품 목록·상세.
5. 수행·도입·납품사례 목록·상세.
6. 공지·뉴스·자료 목록·상세.
7. FAQ·일반 문의·견적 문의.
8. 빈 목록·이미지 누락·404.

제품은 소개용 카탈로그이며 장바구니·주문·결제 화면을 포함하지 않습니다. 실제 데이터 원본과 라우트 연결은 레이아웃 데이터 모듈 계약에 맞춰 후속 연결합니다.

## 기본 B2B 기업 데모 이미지

판매 패키지와 데모에 사용할 사진은 화면별 신규 원본으로 직접 생성합니다. 도안 PNG를 잘라 실제 에셋으로 사용하지 않습니다.

| 화면 | 필요한 신규 이미지 |
|---|---|
| 홈 히어로 | 밝은 사무실의 실제 협업 장면 1장 |
| 대표 서비스 | 전략·디지털 구축·운영개선 장면 각 1장 |
| 프로젝트 | 고객 업무 흐름 통합 프로젝트 검토 장면 1장 |
| 일반 페이지 | 회사·서비스·프로젝트·인사이트·문의 역할별 전용 장면 5장 |
| 상태 화면 | 사진이 없어도 의미가 유지되는 기본 대체 표현 |

생성 원본은 프롬프트와 함께 에셋 원장에 기록하고, 실제 테마에는 최적화한 WebP 또는 AVIF와 필요한 대체 크기만 포함합니다. 실제 로고·인증·기술 수치·읽어야 할 문구를 이미지에 합성하지 않습니다.

홈 1차 이미지 5종의 프롬프트·크기·런타임 경로는 [홈 이미지 원장](assets/home-images.json)에 기록합니다. 내부 페이지·게시판용 이미지 5종의 역할 매핑과 생성 원본은 [내부 이미지 원장](assets/internal-images.json)에 기록합니다. 데스크톱에서는 제목과 사진을 한 장면으로 합치고, 모바일에서는 사진과 본문을 분리해 글자와 인물의 겹침을 막습니다.

## 레이아웃 데이터 슬롯 기본값

테마만 활성화해도 빈 화면이 나오지 않도록 각 슬롯은 업종에 맞는 기본 콘텐츠를 포함합니다. 레이아웃 데이터 설치기는 슬롯의 `children`을 교체하기 전에 기존 기본값을 보존하고, 제거 시 적용값이 변조되지 않았을 때만 기본값을 복원합니다. 팩이 설치되지 않은 상태의 화면과 팩 설치 후 화면이 모두 완성된 구성을 유지해야 합니다.

## 1차 평가 기준

- 1440px PC와 390px 모바일에서 메뉴와 핵심 행동이 보이는가.
- 한글 제목이 두세 줄로 늘어나도 겹치거나 잘리지 않는가.
- 사진을 바꾸거나 누락해도 섹션 구조가 유지되는가.
- 홈에서 사업분야 → 프로젝트 → 인사이트 → 문의 흐름이 분명한가.
- 공통 클래스가 JSON UI의 반복을 줄이면서 페이지별 조형을 제한하지 않는가.
