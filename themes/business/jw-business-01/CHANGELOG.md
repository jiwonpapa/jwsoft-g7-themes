# 변경 이력

## 0.1.0 — 2026-09-10 (개발)

- 홈·프로젝트·서브페이지 제목을 역할별 반응형 타입 토큰으로 조정하고 강제 줄바꿈과 한글 글자 단위 분리를 제거했습니다.
- 일반페이지 상단과 본문 안내를 회사·서비스·정보·문의 유형별 문구로 분리하고 원시 수정 시각 노출을 제거했습니다.
- 일반페이지 10개는 실제 생성 완료 수량이 아니라 레이아웃 데이터 설치 대상 계약임을 문서에 명확히 표시했습니다.
- 최신 홈 PC·모바일 미리보기와 한글 제목 단어 단위 줄바꿈.
- SIR 판매 근거에 따라 첫 상품을 일반 기업/회사 홈페이지용 `JW BUSINESS 01`로 확정.
- 산업설비 시안을 출시 대상에서 제외하고 범용 B2B 기업 데모의 콘텐츠·이미지로 교체.
- G7 설치 가능한 기업 템플릿 기본 구조, 슬롯 계약 5개, 공개 콘텐츠 경로 5개.
- 10개 일반 페이지·4개 게시판·2단 주 메뉴·푸터 메뉴를 정의하는 기계 판독형 사이트 구조 계약.
- raw node ID 기반 편집 경계, 네이티브 번들 export/manifest, HTML 정화와 기본 접근성.
- 첫 A 디자인의 홈 JSON UI, 페이지·게시판·게시물 내부 레이아웃, 반응형 시멘틱 CSS와 직접 생성한 WebP 이미지 10종.
- 회사·서비스·프로젝트·인사이트·문의 내부 화면에 역할별 히어로 이미지와 낮은 강도의 패럴랙스, 모바일 분리 구성을 적용.
- 회사소개·가치·연혁·팀·서비스·과정·FAQ·연락처·위치·개인정보용 네이티브 페이지 콘텐츠 계약과 반응형 스타일.
- 인증·파트너와 소개형 제품·사양 블록을 시멘틱 페이지 계약과 반응형 스타일에 추가하고 설치 모듈용 콘텐츠 계약 경로를 공개.
- 게시판 PC·모바일 페이지당 5건과 최소 6건을 고정하고, 설치·라우트·두 번째 페이지·제거 보존을 검사하는 레이아웃 데이터 스키마를 추가.
- Motion DOM/WAAPI 기반 이미지 패럴랙스와 위·좌·우 등장 효과, 동작 줄이기 및 무스크립트 콘텐츠 노출.
- Lucide 단색 SVG 아이콘을 홈·페이지·게시판·문의의 탐색과 주요 행동에 적용하고 유니코드 UI 아이콘을 제거.
- 설치·프리셋·사이트 구성·업데이트·접근성 기준을 정리한 한국어 구매자 안내 문서.
- 헤더·히어로·모바일 메뉴 각 3종과 제한된 G7 편집기 스펙.
- 로컬 G7 설치·활성화·업데이트, 홈 공개 렌더와 1440px·390px 대표 동작 확인.
- G7 편집기 한·영 라벨과 이미지 선택기, 히어로 프리셋 저장·재진입·원형 복원 확인.
- 공개 `sirsoft-board` 계약으로 비회원 작성·비밀글 암호 열람·오류·수정과 모바일 폼 확인.
- `seo-config.json` 시멘틱 매핑과 크롤러 내부 링크, `layout-strategy=keep` 고객 편집 보존 확인.
- 실제 데이터 팩 연결은 미완료.
- 쇼핑 비포함 범위에 맞춰 과거 제품·분류 초안 레이아웃 제거.
