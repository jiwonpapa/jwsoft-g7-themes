# JW BUSINESS 01 — 첫 일반 기업 테마 기획

작성: 2026-09-08. 갱신: 2026-09-10. 상태: SIR 판매 근거에 따라 일반 기업/회사 테마로 확정. 범용 B2B 기업 홈, 공통 내부 레이아웃, 방문자 문의 흐름과 구조 프리셋 3군을 구현했습니다. 로컬 G7 설치·편집·모바일·검색엔진 HTML·고객 편집 보존을 확인했고 실제 데이터 팩 연결은 진행 중입니다.

## 상품 정의

`JW BUSINESS 01`은 **일반 기업/회사 홈페이지**를 위한 첫 유료 테마입니다. SIR 콘텐츠몰에서 누적 구매와 베스트 노출이 반복 확인되는 범용 기업형을 첫 상품 분야로 선택했습니다. 특정 업종 전용 상품이 아니라 회사소개, 사업·서비스/제품, 사례, 소식·자료, 문의로 이어지는 공통 정보구조와 여러 화면 구성을 제공합니다.

- 테마군: `JW BUSINESS`
- 상품명: `JW BUSINESS 01`
- 개발 폴더: `jw-business-01`
- G7 설치 식별자: `jwsoft-business01`
- 쇼핑몰: 제외. 결제·주문·배송 기능은 포함하지 않음
- 기본 데모 프로필: `일반 기업 > B2B 기업서비스형`
- 기본 데모 사업체: 전략·디지털 구축·운영개선을 제공하는 가상 기업 `NOVA WORKS`

산업설비 전용 시안은 첫 상품 선정 근거가 부족해 출시 대상에서 제외했습니다. 기존 이미지와 도안은 `design/archive/industrial-prototype`에 보류 자료로만 보존합니다.

## 구매자가 받는 범위

한 개의 홈 화면만 판매하지 않습니다. 공통 기업 사이트를 완성할 수 있는 페이지와 선별된 구조 선택지를 한 테마 패키지에 제공합니다.

| 묶음 | 제공 대상 |
|---|---|
| 홈 | 기업 소개형 홈, 선택 가능한 헤더·히어로·주요 섹션 조합 |
| 회사 | 회사소개, 비전·가치, 연혁, 조직·팀, 인증·파트너, 사업장·오시는 길 |
| 사업 | 사업분야 또는 서비스 목록·상세, 진행 과정, 강점 |
| 소개형 제품 | 일반 페이지·게시판으로 구성하는 제품 소개, 사양, 관련 자료·사례, 문의 연결 |
| 실적 | 수행·도입·납품사례 목록·상세, 갤러리 |
| 정보 | 공지·뉴스, 자료실·다운로드, FAQ의 목록·상세 |
| 전환 | 일반 문의·견적 문의, 연락처, 위치, 개인정보 안내 |
| 공통 상태 | 빈 목록·없는 페이지·없는 게시물·401·403·404·500·503·점검 화면 |

페이지는 G7 네이티브 페이지·게시판과 연결합니다. 같은 원본을 테마 자체 DB나 별도 편집 문서로 복제하지 않습니다. 실제 제공 완료 여부는 구현·G7 검증 결과로 갱신합니다.

## 구조 선택지

구조 선택지는 무제한 빌더가 아니라 테마 품질을 유지하는 **검증된 프리셋**입니다. 메뉴와 콘텐츠는 하나의 논리 구조를 공유하고 PC·모바일 표현만 달라집니다.

### 헤더·PC 메뉴 3종

| 식별자 | 구성 | 적합한 사이트 |
|---|---|---|
| `header-standard` | 흰 배경, 로고·1단 메뉴·강조 버튼 | 대부분의 일반 기업 |
| `header-overlay` | 히어로 위 반투명 헤더와 흰 메뉴 | 사진 중심 기업·브랜드 |
| `header-directory` | 로고와 주요 메뉴를 두 줄로 분리 | 메뉴가 많은 기업 |

### 히어로 3종

| 식별자 | 구성 | 용도 |
|---|---|---|
| `hero-cover` | 전체 폭 이미지 위 제목·설명·최대 2개 행동 | 현장·공간·브랜드 인상 강조 |
| `hero-split` | 텍스트와 이미지의 2열 구성 | 서비스 설명과 행동을 균형 있게 전달 |
| `hero-editorial` | 넓은 여백, 큰 문장, 제품 또는 인물의 분리된 이미지 | 전문성·기술·브랜드 메시지 강조 |

### 모바일 메뉴 3종

| 식별자 | 구성 | 사용 기준 |
|---|---|---|
| `mobile-panel` | 헤더 아래 펼침 패널 | 메뉴가 짧은 기본형 |
| `mobile-drawer` | 오른쪽 슬라이드 패널 | 일반적인 기업 메뉴 |
| `mobile-fullscreen` | 전체 화면 메뉴와 고정 문의 행동 | 브랜드·사진 중심 헤더 |

각 모바일 메뉴는 키보드 조작, 포커스 이동·복귀, ESC 닫기와 배경 스크롤 잠금을 같은 계약으로 지원합니다. 1단 메뉴 기준의 `mobile-panel`·`mobile-drawer`·`mobile-fullscreen`을 구현했습니다. 현재 메뉴 표시와 다단 메뉴는 실제 메뉴 데이터 계약과 함께 검증합니다.

### 공통 블록

- 기업 소개·핵심 문장·비전/가치
- 사업·서비스·제품 목록과 상세 진입
- 대표 사례·프로젝트·갤러리
- 과정·방법·강점
- 팀·전문가·조직
- 인증·파트너·다운로드 자료
- 공지·뉴스·FAQ
- 연락처·위치·문의·견적 행동

일반 페이지 본문은 `contracts/page-content.json`의 시멘틱 콘텐츠 클래스로 표현합니다. 회사소개·가치·연혁·팀·인증·파트너·서비스·소개형 제품·진행 과정·FAQ·연락처·위치·개인정보의 서로 다른 정보 구조를 한 `page/show` 라우트에서 일관되게 렌더링합니다. FAQ는 별도 스크립트 없이 네이티브 `details`/`summary`를 사용합니다. 테마가 표현용 내부 히어로 이미지를 제공하고, 실제 본문 문구·콘텐츠 이미지·메뉴는 G7 페이지 원본과 레이아웃 데이터 팩이 소유합니다.

홈과 대표 내부 흐름은 Motion의 DOM/WAAPI 경량 경로로 섹션 등장과 이미지 스크롤 깊이를 표현합니다. 회사·서비스·프로젝트·인사이트·문의에는 서로 다른 직접 생성 사진을 연결하고, 모바일에서는 사진과 제목을 분리합니다. 아이콘은 Lucide 단색 선형 SVG만 허용하고 버튼·역량·서비스·자료·첨부 탐색에 사용합니다. 컬러 아이콘·이모지·유니코드 기호를 인터페이스 아이콘으로 사용하지 않습니다.

수치·인증·파트너 로고는 실제 데이터가 있을 때만 노출합니다. 블록별 허용 필드·반복 항목·순서 변경 범위는 공개 editor spec으로 제한합니다.

## 메뉴와 레이아웃 프로필

테마는 위 공통 페이지와 구조를 제공하고, 레이아웃 데이터 팩은 업종에 맞는 메뉴 조합·문구·이미지·게시판·게시물을 설치합니다.

| 프로필 예시 | 기본 메뉴 조합 |
|---|---|
| 일반 B2B 기업 · 기본 | 회사소개 / 사업분야 / 프로젝트 / 인사이트 / 문의 |
| 제품소개형 | 회사소개 / 사업소개 / 제품소개 / 적용사례 / 고객지원 |
| 전문서비스형 | 소개 / 업무분야 / 전문가 / 수행사례 / 칼럼·상담 |

프로필은 필요한 페이지만 활성화하고 존재하지 않는 페이지나 게시판 링크를 남기지 않습니다. 설치 모듈은 실제 G7 객체를 생성한 뒤 논리 키를 실제 URL과 ID로 해석해 PC·모바일·푸터 메뉴에 연결합니다.

## 기본 B2B 기업 데모

기본 데모는 선택한 A 도안의 화이트·잉크 네이비·블루 규격과 넓은 여백을 유지합니다. 가상 기업 `NOVA WORKS`가 사업 전략, 디지털 서비스 구축, 업무 프로세스 개선을 제공하는 실제 회사처럼 구성합니다. 홈 JSON UI, Tailwind `@apply` 기반 시멘틱 CSS, 구조 프리셋 3군과 홈·내부 화면용 직접 생성 이미지 10종을 이 방향으로 구현했습니다.

첫 판매 데모는 아래 공통 기업 구조를 실제 G7 객체로 설치합니다. 하위 업종마다 새 사이트 구조를 만들지 않고, 일반 기업이 바로 교체해 쓸 공통 페이지에 한정합니다.

| 상위 메뉴 | 실제 도착점 | 데이터 팩 최소 수량 |
|---|---|---|
| 회사소개 | 회사소개, 비전·가치, 연혁, 팀, 오시는 길 | 일반 페이지 5개 |
| 사업분야 | 서비스 개요, 진행 과정 | 일반 페이지 2개. 서비스 3종은 개요 안에서 각각 충분한 본문·이미지·문의 링크 제공 |
| 프로젝트 | 프로젝트 목록·상세 | 게시판 1개, 서로 다른 사례 6건, 목록 2페이지 |
| 인사이트 | 인사이트, 공지, FAQ | 게시판 2개와 FAQ 페이지 1개. 인사이트 6건·공지 6건 |
| 문의하기 | 상담 안내, 비회원 비밀 문의 작성, 개인정보 안내 | 일반 페이지 2개와 문의 게시판 1개. 개인정보 없는 데모 문의 6건 |

PC·모바일 주 메뉴는 같은 2단 논리 트리를 사용합니다. 데스크톱은 hover와 `focus-within`으로 하위 메뉴를 열고, 모바일은 열린 메뉴 안에 하위 항목을 항상 표시합니다. 모듈은 leaf `A`, branch `Div([label, Div(children)])`의 범용 노드만 만들고 테마가 구조 선택자로 표현합니다. 데이터 팩 설치 전의 1단 기본 메뉴도 정상 표시해야 합니다.

각 게시판은 PC·모바일 `per_page`를 5로 설정하고 최소 6건을 설치해 첫 화면과 두 번째 화면에 실제 콘텐츠가 존재하도록 합니다. 5건은 [공식 게시판 모듈 설정의 허용 최솟값](https://github.com/gnuboard/g7-module-sirsoft-board/blob/main/config/board.php)입니다. 설치 검증은 홈·모든 페이지·모든 게시판·문의 작성 화면과 고객 수정 보존 제거 조건을 `layout-data.json`에서 기계 판독 대상으로 선언합니다.

이 구조는 `contracts/site-structure.json`에 기계 계약으로 고정합니다. 테마가 요구하는 페이지·게시판·메뉴 목적과 논리 키를 제공하고, 설치 모듈이 실제 G7 객체 ID와 URL을 생성해 `layout-data.json`의 슬롯에 연결합니다. 계약에는 실제 게시물 문구나 이미지를 넣지 않습니다.

게시물·이미지 관계는 AI로 미리 제작·검토한 고정 팩으로 제공하며 랜덤 데이터로 생성하지 않습니다. 회사·서비스·사례·인사이트 이미지가 같은 회의 장면을 반복하지 않도록 대상·구도·본문 관계를 원장에 기록합니다. 공지와 FAQ는 내용상 이미지가 필요한 항목에만 사용합니다.

이 테마에는 장바구니·구매 옵션·주문·결제·배송·재고 화면을 넣지 않습니다. 쇼핑이 필요한 상품은 별도 테마 또는 이커머스 기능 조합으로 기획합니다.

## 상품 경계

- 테마는 디자인, 공통 페이지, 프리셋, 반응형 표현, 공개 편집 규칙을 소유합니다.
- G7은 인증, 페이지·게시판 원본, 파일, 렌더링, 저장·Undo를 소유합니다.
- 레이아웃 데이터 모듈은 메뉴·페이지·게시판·게시물·이미지의 생성과 연결을 담당합니다.
- 예약·주문·매물·LMS 등 상태가 있는 업무 기능은 별도 모듈이 소유합니다.
- 구매자 서버에서 Node·npm·Python이나 외부 CDN을 요구하지 않도록 빌드 자산을 테마 ZIP에 포함합니다.

## 제작 순서와 완료 조건

1. 일반 기업 공통 페이지와 세 구조군의 계약·디자인 규격을 확정합니다.
2. 범용 B2B 기업 데모 홈을 실제 G7에 설치해 PC·모바일 시각과 편집 계약을 확인합니다.
3. 회사·사업·소개형 제품·사례·정보·문의에 공용하는 페이지·게시판 내부 레이아웃을 구현합니다.
4. 위 일반 기업 레이아웃 데이터 팩을 삽입해 실제 2단 메뉴·일반 페이지·게시판 2페이지·문의·이미지 연결을 확인합니다. **진행 중**
5. 헤더·히어로·모바일 메뉴 프리셋을 구현하고 대표 조합의 반응형·접근성을 검사합니다. **완료**
6. 설치 ZIP, 사용 문서, 라이선스, 고객 수정 보존을 확인합니다. **테마 ZIP·보존 완료, 팩 통합 문서 남음**

첫 상품을 완성하기 전 공통 인프라를 독립 과제로 확장하지 않습니다. 하네스·헌법·공통 코드는 위 구현에 필요한 만큼만 보완하고, 두 번째 실제 테마에서 중복이 확인될 때 공통 기반으로 승격합니다.
