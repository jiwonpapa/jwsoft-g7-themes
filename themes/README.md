# 테마 작업 공간

현재 [JW BUSINESS 01](business/jw-business-01/product.md)을 일반 기업 홈페이지용 첫 상품으로 제작 중입니다. 전략·디지털 구축·운영개선을 제공하는 범용 B2B 기업이 첫 데모 프로필이며 A 도안의 조형을 적용한 홈 MVP까지 구현되어 있습니다. 산업설비 전용 시안은 출시 대상에서 제외했습니다.
실제 상품이 없는 상태에서 여러 업종의 빈 테마를 대량 생성하지 않습니다.
기획서 양식은 [theme-brief](../templates/theme-brief.md), 기본 범위는 [MVP](../docs/mvp.md)를 사용합니다.
