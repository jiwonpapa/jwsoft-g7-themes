## 모듈의 실제 역할

분야별 메뉴 트리, 게시판 정의, 쇼핑 분류, 분류별 상품·옵션·이미지, 게시물과 페이지를 데이터셋에 사전 준비합니다.
설치 모듈은 게시판·상품 분류를 생성하고 해당 대상에 콘텐츠를 등록하며 마지막으로 실제 주소와 메뉴·홈을 연결합니다.

검증·설치 이력·재개·선택 제거는 이 흐름을 지원하는 기능입니다. 데이터와 모듈을 분리하는 별도 제품이 아니며 모든 관리 기능 완성을 데이터 기획의 선행 조건으로 삼지 않습니다.

## 저장소와 배포

초기에는 새 프로젝트 하나에서 데이터셋과 설치 모듈을 함께 관리합니다. 모듈 ZIP과 팩 ZIP은 독립 버전·배포물로 만듭니다.
G7 업데이트 경로가 별도 모듈 배포 저장소를 요구하는지는 실제 패키징 때 확인합니다. 추가 저장소 생성을 초기 기획의 전제로 두지 않습니다.
테마 디자인·편집 규칙은 현재 테마 저장소에 유지합니다.

## 다음 순서

1. 메뉴별 필요 데이터·G7 생성 동작·참조·검사 기준을 한 기획표로 작성.
2. 대표 실제 콘텐츠와 해당 구성을 생성하는 모듈·검사를 함께 개발.
3. 전체 분야 데이터·게시판·상품 분류·상품·옵션·이미지로 확장.
4. 실제 G7 홈페이지에서 확인한 뒤 팩과 설치 모듈을 각각 배포.

이 문서는 인계 위치와 테마 연동 경계만 유지합니다. 세부 팩 규격·업데이트·하네스의 기준 문서는 새 프로젝트에서 관리합니다.
