작성 기준: 2026-09-08. 이 저장소는 유료 테마 제작을 이어갈 수 있도록 준비한 초기 문서 프로젝트입니다.

## 이번에 준비한 것

- 별도 비공개 Git 저장소와 Codex용 AGENTS.md.
- 제작 헌법, 초기 MVP, 도안 선정 절차, 디자인 규격과 패키징·검증 정책 초안.
- 업종별 테마 기획서 양식과 5차 로드맵.

테마 구현, 디자인 도안 생성, 공통 라이브러리, CI, 자동 검사기, 상품 판매 시스템은 아직 없습니다.
폴더의 README나 문서에 등장하는 도구 이름은 실행 가능한 명령이 아닙니다.

## 이어받아 유지할 방향

1. G7/PB와 별도 저장소에서 여러 업종의 유료 테마를 관리합니다.
2. 개발 시 공통 원본을 재사용하고 판매 시 필요한 자산·규칙·개발 도구를 테마별로 묶습니다.
3. 동종 유료 테마를 조사한 후 디자인 방향 2~3개를 이미지로 제시하고 형님이 선택합니다.
4. 실제 구현은 선택한 디자인의 토큰·섹션 규칙과 G7 공개 계약에 맞춥니다.
5. 첫 테마 하나를 완성하고 두 번째 업종에서 재사용성을 확인합니다.

## 다음 작업 제안

먼저 첫 업종을 정하고 `templates/theme-brief.md`를 해당 테마의 `product.md`로 작성합니다.
업종이 정해지면 동종 상품 3~5개만 조사해 페이지 구성·전환 흐름·편집 방식·에셋 조건을 비교합니다.
이후 동일한 실제 한글 콘텐츠를 사용한 도안 2~3개를 제시합니다.
첫 구현 전에 G7 대상 버전과 대표 페이지에 필요한 기능만 확인합니다.

복사해서 사용할 시작 요청 예시:

> 이 저장소의 START-HERE와 MVP를 읽고, 첫 테마를 [업종]으로 기획해라. 동종 유료 테마 3~5개를 근거로 페이지 구성과 상품 범위를 제안하고, 같은 콘텐츠로 디자인 방향 3개를 이미지로 제시해라. 선택한 뒤 실제 G7 구현으로 진행한다.
