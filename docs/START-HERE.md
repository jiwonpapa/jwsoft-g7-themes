# 다음 작업을 시작하는 곳

작성 기준: 2026-09-10. 첫 상품은 일반 기업 홈페이지용 `JW BUSINESS 01`입니다. 범용 B2B 기업 홈과 G7 네이티브 페이지·게시판을 표시하는 공통 라우트 레이아웃, 구조 프리셋 3군, 기계 판독형 사이트 구조 계약을 구현했습니다. 계약에는 일반페이지 10개가 정의되어 있지만 실제 G7 페이지 10개와 2단 메뉴가 설치된 상태는 아닙니다. 다음 핵심은 레이아웃 데이터 팩으로 실제 객체를 만들고 전체 링크를 검증하는 작업입니다.

`JW BUSINESS 01`은 일반 기업용 헤더·히어로·모바일 메뉴와 G7 페이지·게시판 공통 표현을 제공하는 테마입니다. 선택한 A 도안의 조형으로 홈 JSON UI, Tailwind `@apply` 기반 시멘틱 CSS, 공통 페이지·게시판 목록/상세/작성·오류 라우트 레이아웃, 각 3종 프리셋과 직접 생성한 홈·내부 화면 이미지 10종을 구현했습니다. `contracts/site-structure.json`은 설치 모듈이 생성해야 하는 일반페이지 10개·게시판 4개·2단 메뉴를 정의합니다. 이 수치는 현재 사이트에 생성된 페이지 수가 아닙니다. 실제 레이아웃 데이터 팩 연결과 전체 목적지 검증은 아직 남아 있으며 쇼핑몰은 포함하지 않습니다.

## 이어받아 유지할 방향

1. G7/PB와 별도 저장소에서 여러 업종의 유료 테마를 관리합니다.
2. 개발 시 공통 원본을 재사용하고 판매 시 필요한 자산·규칙·개발 도구를 테마별로 묶습니다.
3. 동종 유료 테마를 조사한 후 디자인 방향 2~3개를 이미지로 제시하고 형님이 선택합니다.
4. 실제 구현은 선택한 디자인의 토큰·섹션 규칙과 G7 공개 계약에 맞춥니다.
5. 첫 테마 하나를 완성하고 두 번째 업종에서 재사용성을 확인합니다.
6. AI로 업종에 맞는 게시물·상품·옵션·이미지를 사전 제작하고 내용·관계를 점검해 고정 팩으로 배포합니다. 고객의 전용 설치 모듈은 완성된 데이터를 G7에 삽입합니다. 벤치마크 모듈·데이터·생성 코드는 이번 설계에서 제외합니다.
7. `JW BUSINESS 01` 안에서 공통 기업 페이지와 검증된 구조 프리셋을 제공하고, 업종별 프로필·데이터 팩으로 메뉴와 콘텐츠를 구성합니다. 예약·쇼핑·매물·LMS는 선택 기능 모듈과 연결 화면으로 구분합니다. 여섯 테마군 후보는 수요 순위나 전체 제작 확정이 아닙니다.

## 다음 작업 제안

범용 B2B 레이아웃 데이터 팩으로 회사·서비스·프로젝트·인사이트·문의 데이터를 실제 생성하고 테마 슬롯과 연결합니다. 설치된 데이터로 PC·모바일 메뉴, 목록·상세·문의, 팩 재설치·제거의 고객 수정 보존을 확인합니다.

[레이아웃 데이터 프로젝트](https://github.com/jiwonpapa/jwsoft-g7-layout-data)는 범용 B2B 기업 데모의 메뉴 트리·게시판·게시물·이미지를 실제 생성·등록·연결하는 계약으로 함께 맞춥니다. 테마는 표현과 페이지 구조를, 모듈은 실제 G7 데이터 생성을 담당합니다. G7/레이아웃 데이터 저장소 수정은 해당 범위의 사용자 지시가 있을 때 진행합니다.

복사해서 사용할 시작 요청 예시:

> JW BUSINESS 01 기획서와 디자인 규격을 읽고, 현재 범용 B2B 기업 홈을 실제 G7에서 먼저 검증해라. 그 결과를 반영한 뒤 일반 기업 공통 내부 페이지와 대표 헤더·히어로·모바일 메뉴 조합을 구현해라.
