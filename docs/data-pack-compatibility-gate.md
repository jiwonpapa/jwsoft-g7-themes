# 테마·레이아웃 데이터 팩 호환성 게이트

기준: 2026-09-10. 대상: `JW BUSINESS 01`과 `nova-works-business-services` 팩.

## 목적

테마 설치 ZIP과 데이터 팩이 각각 자체 검사를 통과해도 사이트 구조가 다르면 완성된 데모가 나오지 않습니다. `verify-data-pack`은 실제 G7에 쓰기 전에 테마가 선언한 페이지·게시판·메뉴·슬롯과 팩의 데이터를 직접 대조합니다.

```text
python3 -m tools.theme_harness verify-data-pack \
  themes/business/jw-business-01 \
  /path/to/nova-works-business-services
```

마지막 인수에서는 디렉터리 대신 실제 배포 ZIP을 같은 명령에 넣습니다.

## 통과 조건

- `profile.theme_identifier`와 테마 설치 식별자 일치
- 테마가 선언한 일반 페이지 key·slug 전부 존재
- 테마가 선언한 게시판 key·slug·페이지 크기·정렬 조건 일치
- 게시판별 최소 데모 게시물 수 충족
- PC·모바일 공용 2단 메뉴와 푸터 메뉴 일치
- 테마 슬롯별 참조 존재와 허용 유형 일치
- 페이지·게시물의 첨부 이미지와 본문 논리 참조 전부 해석 가능
- 이미지 파일의 bytes·SHA-256 일치
- 팩 manifest의 파일 목록·bytes·SHA-256·counts가 실제 입력과 일치
- 쇼핑 비포함 테마에서는 분류·상품 데이터가 비어 있음

이 게이트 통과는 실제 설치 성공을 뜻하지 않습니다. 다음 단계에서 데이터 설치 모듈로 깨끗한 G7에 테마 ZIP과 팩 ZIP을 설치하고 PC·모바일 메뉴, 페이지, 게시판 목록 2페이지, 상세, 문의 작성, 이미지, 제거·재설치와 고객 수정 보존을 확인해야 합니다.

## 현재 대조 결과

2026-09-10 작업 중인 팩 디렉터리를 읽기 전용으로 검사했을 때 44개 불일치를 검출했습니다. 프로젝트 6건·인사이트 6건과 연결 이미지 13장은 현재 파일에 존재합니다. 남은 주요 차이는 필수 일반 페이지 7개, 공지 게시판과 게시물, 문의 데모 게시물, 2단 메뉴, 게시판 정렬 조건, 최종 manifest 갱신입니다. 작업 중인 팩 파일은 최종 배포 입력이 아니므로 통과 판정에 사용하지 않습니다.
