# 5차 제작 로드맵

상태 기준: 2026-09-08. 프로젝트·참조 문서 준비만 완료했으며 아래 구현 차수는 시작하지 않았습니다.

| 차수 | 목표 | 주요 산출물 | 완료 판단 | 현재 상태 |
|---|---|---|---|---|
| 1차 | 최소 제작 기반 | 첫 테마에 필요한 토큰 규격·G7 연결·검사 선택·패키징 최소 기능 | 선택한 범위가 실행되고 과잉 검사 없이 설명됨 | 계획 |
| 2차 | 첫 업종 기획·도안 | 업종 기획서·벤치마크·방향 2~3개·선정 디자인 | 사용자 선택과 제품 범위 기록 | 계획 |
| 3차 | 첫 테마 완성 | 대표 구현 후 전체 페이지·편집·설치·문서 | MVP의 해당 테마 완료 조건 충족 | 계획 |
| 4차 | 다른 업종으로 재사용 검증 | 두 번째 테마와 필요한 공통화 | 다른 정보 구성·시각 정체성으로 독립 설치 | 계획 |
| 5차 | 분야별 확장·출시 운영 | 테마별 버전·패키지·지원표·변경 범위 검사 | 각 상품이 독립적으로 제작·출시 가능 | 계획 |

차수는 책임 구분입니다. 첫 업종 요구를 알아야 하는 1차 구현은 2차 기획과 필요한 만큼 맞물려 진행합니다.
업종 선택 전 범용 플랫폼을 먼저 완성하려고 하지 않습니다. 첫 실행은 START-HERE의 업종 선정·기획부터입니다.

## 상태 기록 원칙

현재 단계와 미완료 항목을 이 문서에 간단히 갱신합니다. 작은 문서 프로젝트에 별도 상태 DB·서명 원장·자동 감사 체계를 만들지 않습니다.
필요해지면 `기획 / 디자인 선택 / 구현 / 확인 / 출시`를 테마별 product 문서에 기록합니다.
기존 Page Builder의 NE/EP 차수와 증거를 이 저장소의 완료 수로 합산하지 않습니다.
