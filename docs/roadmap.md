# 5차 제작 로드맵

상태 기준: 2026-09-10. 첫 상품 `JW BUSINESS 01`의 범용 B2B 홈, 공통 내부 레이아웃, 방문자 문의 흐름과 구조 프리셋 3군을 구현했습니다. 로컬 G7 설치·편집·모바일·검색엔진 HTML·고객 편집 보존을 확인했고 실제 데이터 팩 연결은 진행 중입니다.

| 차수 | 목표 | 주요 산출물 | 완료 판단 | 현재 상태 |
|---|---|---|---|---|
| 1차 | 최소 제작 기반 | 첫 테마에 필요한 토큰·검사·빌드·패키징 | 테마 소스와 빌드가 같은 계약으로 검사됨 | 하네스·개발 ZIP·로컬 G7 설치 확인 |
| 2차 | 첫 상품 기획·도안 | 일반 기업 상품 범위·벤치마크·방향 2~3개·선정 디자인 | 사용자 선택과 제품 범위 기록 | BUSINESS 01 및 A 도안 확정 |
| 3차 | 첫 테마 완성 | 범용 B2B 기업 대표 구현 후 공통 페이지·구조 프리셋·편집·설치·문서 | MVP의 해당 테마 완료 조건 충족 | 테마·편집·문의·설치·업데이트 보존 확인, 실제 데이터 팩 통합 중 |
| 4차 | 다른 업종으로 재사용 검증 | 두 번째 테마와 필요한 공통화 | 다른 정보 구성·시각 정체성으로 독립 설치 | 계획 |
| 5차 | 분야별 확장·출시 운영 | 테마별 버전·패키지·지원표·변경 범위 검사 | 각 상품이 독립적으로 제작·출시 가능 | 계획 |

차수는 책임 구분입니다. 일반 기업 테마의 공통 구조와 첫 범용 B2B 기업 데모 요구를 함께 확인하면서 필요한 기반만 보완합니다.
범용 플랫폼을 먼저 완성하려고 하지 않습니다. 다음 범위는 `JW BUSINESS 01`의 공통 내부 페이지와 구조 프리셋 구현, 범용 B2B 기업 데이터 팩의 실제 연결입니다.

## 상태 기록 원칙

현재 단계와 미완료 항목을 이 문서에 간단히 갱신합니다. 작은 문서 프로젝트에 별도 상태 DB·서명 원장·자동 감사 체계를 만들지 않습니다.
필요해지면 `기획 / 디자인 선택 / 구현 / 확인 / 출시`를 테마별 product 문서에 기록합니다.
기존 Page Builder의 NE/EP 차수와 증거를 이 저장소의 완료 수로 합산하지 않습니다.
