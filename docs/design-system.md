# 디자인 시스템과 섹션 규격 초안

상태: 규격 설계용 참조. 아래 숫자는 첫 기업형 테마의 후보값이며 전 테마의 강제 기준이 아닙니다.

## 토큰의 세 층

1. 기본 값: 색상 단계·간격 단계·글꼴·크기.
2. 의미 역할: surface, text, muted, accent, border, section-space, content-width.
3. 컴포넌트: 버튼·카드·헤더 등이 의미 역할을 사용하고 필요한 변형만 선언.

공통화할 것은 토큰의 의미와 구조입니다. 실제 값·밀도·사진 표현은 테마별로 달라집니다.
토큰 원본에서 CSS와 공개 spec의 허용 선택지에 필요한 값을 연결합니다. 두 군데에 수동으로 같은 값을 입력하지 않습니다.
토큰 생성기는 아직 없습니다. G7 native 원본 저장과 토큰의 개발 시 생성물을 같은 문서로 취급하지 않습니다.

## JSON UI와 CSS 작성 규칙

- JSON UI는 페이지 구조·콘텐츠 필드·데이터 소스·슬롯·시멘틱 클래스만 선언합니다.
- 공통 동작은 TypeScript/React, 공통 시각 규칙은 테마 CSS가 소유합니다.
- G7 렌더러가 실제 컴포넌트에 전달하도록 JSON UI의 시멘틱 클래스는 노드 최상위가 아닌 `props.className`에 선언합니다.
- JSON UI에서 동일한 Tailwind 유틸리티 조합을 반복하지 않습니다. 반복되는 역할은 `jw-` 시멘틱 클래스로 올립니다.
- 시멘틱 클래스는 `@layer components`에 두고 Tailwind 유틸리티를 `@apply`로 조합합니다.
- 테마 고유 토큰, 유동 크기, 이미지 비율처럼 일반 CSS가 더 명확한 값은 CSS 변수와 범위 제한 규칙으로 작성합니다.
- 일회성 레이아웃까지 전부 클래스로 추상화하지 않습니다. 실제 두 번째 사용처가 생기면 공통화 여부를 판단합니다.

초기 공통 이름은 `jw-container`, `jw-section`, `jw-section__header`, `jw-eyebrow`, `jw-display-title`, `jw-body-copy`, `jw-button`, `jw-button--primary`, `jw-button--secondary`, `jw-text-link`, `jw-media`로 시작합니다. 상품별 의미가 없는 색상명·숫자명 클래스는 만들지 않습니다.

## 시작값 제안

| 항목 | 첫 기업형 후보값 |
|---|---|
| 본문 폭 | 최대 1200px |
| 화면 좌우 여백 | 모바일 20px / 태블릿 32px / PC 40px |
| 섹션 상하 간격 | 모바일 56px / PC 96px |
| 간격 단계 | 4, 8, 12, 16, 24, 32, 48, 64, 96px |
| 본문 | 16~18px, 행간 1.6~1.75 |
| 제목 | 의미별 크기·굵기·행간과 유동 반응형 값 |
| 강조색 | 기본 강조 1계열, 상태색과 분리 |

## 여백의 소유권

- 화면 가장자리: 공통 Container.
- 섹션 상하: Section의 padding.
- 제목·본문·버튼, 카드 목록의 간격: 부모 Stack/Grid의 gap.
- 카드 내부: Card의 padding.
- 예외적인 겹침·전면 이미지는 해당 섹션 변형에 한정하고 이유를 기록.

자식과 부모가 같은 간격을 margin과 padding으로 중복해서 만들지 않습니다.

## 섹션 계약

각 섹션에 목적, 허용 변형, 텍스트/이미지/링크 필드, 반복 항목, 허용 자식, 반응형 전환, 빈 상태를 적습니다.
반복 항목의 최소·최대 개수는 실제 레이아웃과 업무 요구가 있을 때만 설정합니다.
고정 높이·불필요한 수동 줄바꿈·임의 CSS 입력으로 콘텐츠 문제를 가리지 않습니다.

## 상태·콘텐츠·접근성

- 버튼·링크·입력은 hover/focus/disabled/loading/error 등 사용 상태를 포함합니다.
- 색상 대비·키보드 탐색·명확한 레이블·동작 줄이기 설정을 고려합니다.
- 한글 긴 제목, 영문 긴 단어, 짧거나 많은 목록, 이미지 누락을 대표 콘텐츠로 확인합니다.
- PC와 모바일의 메뉴·정렬·읽는 순서·이미지 크롭을 따로 정의합니다.
- 그림자·라운드·모션은 선택한 시각 방향에 맞춥니다. 모든 테마에 같은 카드 외형을 강제하지 않습니다.

에셋 원장은 파일, 출처, 권리, 동봉 여부, 대체 가능 여부를 기록합니다. 선택하지 않은 대용량 원본이나 다른 업종 에셋까지 모든 테마에 넣지 않습니다.
