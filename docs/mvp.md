# 초기 MVP 기획 v0.1

상태: 참조 초안. 첫 업종·도안·G7 지원 조합은 미선정이며 현재 구현된 테마는 없습니다.

## 목표

한 업종의 완성도 있는 G7 테마 1개를 제작하고, 구매자가 설치→자기 콘텐츠로 편집→저장·재열기→공개 사이트 운영을 할 수 있게 합니다.
테마 수나 섹션 개수보다 이 흐름의 완성도가 우선입니다.

## 첫 업종 후보

- 기업·전문서비스: 소개, 서비스, 실적, 문의 중심으로 범위를 잡기 쉽습니다.
- 건축·인테리어: 프로젝트 목록·상세·사진과 명확한 시각 차별성을 검증하기 좋습니다.
- 실시간 예약·결제·매물 관리가 중심인 업종은 해당 기능 모듈의 준비 상태를 확인한 뒤 선택합니다.

## 첫 상품 범위 초안

| 범주 | 제안 범위 | 확정 방법 |
|---|---|---|
| 핵심 페이지 | 홈, 소개, 서비스 목록·상세, 프로젝트 목록·상세, 문의 | 업종 기획서에서 불필요한 페이지 제거 |
| 공통 영역 | 헤더·푸터·내비게이션·모바일 메뉴 | 선택 도안과 G7 소유권에 맞춤 |
| 운영 화면 | 사용 기능에 해당하는 검색·게시판·로그인 및 404·빈 상태 | 모든 G7 기능 화면을 무조건 제작하지 않음 |
| 편집 | 텍스트·이미지·링크·허용 스타일·반복 항목·허용 구조 | 실제 공개 editor spec 지원 확인 |
| 반응형 | PC·태블릿·모바일과 긴 한글 콘텐츠 | 대표 폭과 경계 폭으로 확인 |
| 제공물 | 설치 ZIP·개발 키트·사용 문서·에셋 권리 목록·데모 | 해당 테마만 독립적으로 구성 |

문의 접수·지도·검색 등은 `G7 기본`, `추가 모듈 필요`, `표현용 콘텐츠`로 분류합니다.
실제 전송 기능이 없으면 전송 완료를 보여주지 않습니다. 전화·이메일 연결 같은 지원 가능한 대안을 기획서에 기록합니다.

## MVP에서 제외할 것

- 여러 업종의 동시 대량 제작, 범용 페이지 편집기 재개발.
- 결제·예약·재고·CRM 자체 구현, 새로운 마켓·라이선스 서버·DRM.
- 모든 G7 모듈·테마·브라우저 버전에 대한 포괄 지원 주장.
- 도안 미선택 상태에서 전체 페이지를 여러 디자인으로 구현.
- 첫 상품과 관계없는 공통 엔진·전체 회귀 하네스 구축.

## 완료 조건

1. 기획서의 페이지·기능 범위와 선택 도안이 구현에 대응합니다.
2. 지정한 G7 지원 조합에 설치되고 해당 테마의 필수 경로가 열립니다.
3. 대표 콘텐츠 편집·구조 변경·Undo·저장·재열기·공개 출력이 선언한 범위에서 동작합니다.
4. 모바일 메뉴, 긴 제목, 빈 목록, 이미지 교체, 오류 상태가 실제 화면에서 확인됩니다.
5. 업데이트 안내와 고객 편집본 보존 동작을 확인합니다. 재설치를 업데이트 대안으로 강제하지 않습니다.
6. 실제 설치 ZIP과 개발 키트가 생성되고 문서·권리 목록·상품 설명이 내용과 일치합니다.

디자인 선택, 소스 구현, 설치·동작 확인, 상품 출시는 각각 기록합니다. 자동 검사가 통과했다는 이유로 디자인 선택이나 판매 승인을 만들어내지 않습니다.
