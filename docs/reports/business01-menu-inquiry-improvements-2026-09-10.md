# JW BUSINESS 01 메뉴·프로젝트·문의 개선

검증일: 2026-09-10. 대상: 테마 `jwsoft-business01` 및 로컬 `https://g7pb.test` (`g7pb-dev`).

## 변경 결과

| 대상 | 원인과 수정 | 실제 확인 |
|---|---|---|
| 프로젝트 목록 | 카드가 아닌 2열 그리드 자체를 반복해 한쪽 열만 사용. 반복을 카드로 이동하고 설명을 2줄로 제한 | PC 2열, 모바일 1열, 6개 게시물의 1·2페이지 |
| 게시물 이미지 | 데모 입력에서 이미지·연관 콘텐츠 참조를 해석하지 않아 `src="#"`, 썸네일 없음 | 프로젝트 6개·인사이트 6개를 G7 첨부파일로 연결, 이미지 12개 HTTP 200 |
| 전체 메뉴 | 일반페이지는 존재하지만 기본 헤더가 상위 링크만 표시 | 계약의 하위 메뉴 추가. PC 드롭다운·키보드 접근, 모바일 그룹 메뉴·페이지 이동 후 닫힘 |
| 언어 | G7이 저장된 `g7_locale`을 우선해 이전 영어 선택을 계속 적용 | 테마 기본 한국어, 공개 `G7Core.locale` API로 전환. 사용자의 EN 선택만 별도 키로 유지 |
| 홈 인사이트 | 목록으로 향하는 고정 항목 | 실제 게시물 API의 최신 3개 제목·분류·상세 링크 표시 |
| 문의 | 연락받을 필드와 접수 안내 부족 | 회신 이메일 필수·회사명 선택. 비공개 본문에 저장, 접수번호·확인 링크 표시 |
| 문의 재열람·수정 | 네이티브 form 기본 동작 방지 시 JSON UI submit 이벤트까지 가릴 위험 | G7 이벤트를 보존하고 필수 항목 검증. 비밀번호 열람과 수정 토큰 전달 확인 |
| 모바일 헤더 | 언어·메뉴 문구가 좁은 폭에서 줄바꿈 | 언어 한 줄 유지, 메뉴 아이콘 버튼, 메뉴 높이 제한과 내부 스크롤 |

## 실제 메뉴 목적지

| 메뉴 | 확인한 일반페이지 및 게시판 |
|---|---|
| 회사소개 | `/page/company`, `/page/values`, `/page/history`, `/page/team`, `/page/location` |
| 사업분야 | `/page/services`, `/page/process` |
| 프로젝트 | `/board/cases`, 2페이지, 상세 |
| 인사이트 | `/board/resources`, `/board/notices`, 각 2페이지·상세, `/page/faq` |
| 문의하기 | `/board/inquiries/write`, `/board/inquiries`, `/page/contact`, `/page/privacy` |

일반페이지 10개는 내장 브라우저에서 제목·본문을 확인했습니다. 홈 인사이트는 실제 상세 26·27·28로 연결됩니다. 회사소개·프로젝트 목록·프로젝트 상세의 크롤러 응답도 제목과 내부 링크를 포함합니다. 문의 작성 경로의 크롤러 응답은 작성 폼을 공개 문서로 제공하지 않습니다.

## 문의 운영 범위

1. 방문자가 이름·작성 비밀번호·회신 이메일·제목·내용을 입력합니다. 회사명은 선택입니다.
2. 기존 G7 게시판 API가 비회원 비밀글로 저장합니다. 별도 DB·인증·메일 엔진은 없습니다.
3. 접수번호와 상세 링크를 보여줍니다. 작성 비밀번호로 내용을 열거나 수정할 수 있습니다.
4. 관리자는 G7의 문의 게시판 관리 화면에서 본문에 저장된 회신 이메일을 확인하고 직접 회신합니다.

제목과 작성자명은 목록에 표시되고 본문이 비공개입니다. 이를 작성 폼·문의 안내·개인정보 안내에 명시했습니다. 수정 시 이메일과 회사명은 기존 본문의 일부로 편집됩니다. 자동 답장·답변 상태 관리·상담 CRM은 구현하지 않았으며 SMTP 실발송도 검증 완료로 주장하지 않습니다. 고객 설치 시 실제 운영 연락처와 개인정보 안내를 운영 조건에 맞게 설정해야 합니다.

## 검증 증거와 경계

- TypeScript strict, Vitest 34개, 테마 빌드·독립 ZIP 패키징 통과.
- 최종 ZIP을 G7 기본 `template:update`로 로컬에 배포했습니다.
- 비회원 시험 문의 41: 작성 → 접수번호 → 비밀번호 열람 → 제목 수정 저장, 이메일 보존과 비밀글 유지 확인. 시험 글은 삭제했습니다. 시험 중 잠시 중지한 게시판 알림 설정도 원상복구했습니다.
- 내장 브라우저에서 PC 하위 메뉴·전체 일반페이지·게시판과 390px 모바일 메뉴를 확인했습니다. 320px에서도 가로 넘침 없이 한국어/영어가 표시됩니다.
- 이전 영어 상태가 있던 Edge에서 한국어 기본 적용, 내장 브라우저에서 EN 선택 후 새로고침 유지 및 한국어 복귀를 확인했습니다.
- 테마 ZIP 업데이트와 로컬 데이터 복구는 별도 작업입니다. 테마 ZIP만 설치한다고 페이지·게시판·게시물·이미지가 생성되는 것은 아닙니다.
- 로컬 데모 첨부파일·본문 참조 복구는 G7 네이티브 서비스로 처리했습니다. 레이아웃 데이터 모듈의 설치·재설치 품질을 검증했다는 의미가 아니며, 다른 프로젝트 소스는 수정하지 않았습니다.
